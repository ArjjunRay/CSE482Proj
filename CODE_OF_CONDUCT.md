# Code of Conduct

We pledge to make participation in this project a harassment-free experience for
everyone. Be respectful, give actionable feedback, accept responsibility for mistakes,
and focus on what is best for the project and community. Harassment, personal attacks,
trolling, and publishing another person's private information are unacceptable.

Report unacceptable behavior through the repository's private security-reporting
channel. Maintainers may remove, edit, or reject contributions and may temporarily or
permanently ban contributors whose behavior violates this code.

This policy is adapted from Contributor Covenant 2.1.
